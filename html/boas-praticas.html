Uma coisa que ficou na cabeça de uma aula

Não vou fingir que lembro a frase palavra por palavra, mas o que ficou de uma explicação em aula foi mais ou menos isso:

tag n é enfeitte, cada um tem que significar alguma coisa no conteudo, não so pra funcionar visualmemte

Foi meio isso que eu tentei seguir aqui: usar as tags semânticas certas (HTML puro) em vez de jogar tudo dentro de div, mesmo sem CSS pra "disfarçar" nada.

Checklist de boas práticas

nome de variável decente

Já perdi tempo demais mexendo em código meu de x1, temp e outras variáveis assim que eu mesmo não lembrava o que faziam duas semanas depois. Hoje tento usar nome que explica, tipo calcularMediaFinal, mesmo que fique mais longo de digitar.

comentário bom explica o porquê

// soma 1 a i não serve pra nada, o código já mostra isso sozinho. Já // avança pro próximo da fila de espera explica uma coisa que só olhando pro código eu não ia saber na hora.

testar aos pedaços

Eu tinha o costume de escrever um monte de linha antes de rodar pela primeira vez, e aí quando dava erro eu não fazia ideia de onde. Testando aos poucos fica bem mais fácil de achar o problema.
