comparando 3 linguagens

Toda vez que alguém me pergunta qual linguagem começar, eu penso nessas três. Montei uma tabela ai comparando elas

Python x JavaScript x Java
Linguagem Paradigma principal Uso mais comum
Python Multiparadigma (imperativo, orientado a objetos) Ciência de dados, automação, backend
JavaScript Orientado a objetos baseado em protótipos Front-end web
Java Sistemas corporativos e Android
As três linguagens aparecem, ano após ano, entre as mais usadas em pesquisas como a Stack Overflow Developer Survey.

ainda não sei qual linguagem escolher, e agora?

Foi exatamente minha dúvida no começo. O que ajudou foi escolher pelo que eu queria fazer, não pela linguagem que todo mundo comenta. Se é mexer com dados, dá pra ir de Python direto. Se é site, JavaScript cedo ou tarde vai aparecer. No fim a lógica é bem parecida entre uma e outra

erro que eu cometi: achar que tinha que saber tudo antes de codar

Eu ficava lendo teoria e mais teoria antes de abrir o editor, achando que ia "não estar pronto". Só que na prática o que resolveu foi ir fazendo projeto pequeno e ir quebrando a cara, consultando doc quando travava.
